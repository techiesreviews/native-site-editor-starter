Meadow Row Allotments

A small site for forty plot holders: rules, a plot map, seasonal notices, and a way to reach the committee.

The brief

The allotment committee kept its rules in a folder of photocopies and its notices on a board by the gate. New plot holders often missed both, and the committee changes every few years, so whatever we built had to be easy to hand on.

What we built

A short site with the rules on one page, a plot map drawn as a simple image, a notices page ordered by season, and a contact page that names the current committee. A one-page guide explains how to change each of them.

Since launch

The site has already passed to a new committee secretary, who took it over using the written guide alone.
